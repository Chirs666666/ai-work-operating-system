# AI Work Operating System v1.0.0
A GitHub source-of-truth + Codex runtime distribution for SEO and independent website projects.

1. Push this complete folder to a private GitHub repository.
2. Expose/install the skill directories for Codex; GitHub remains the versioned source.
3. Copy `project-template/` for each real site/client project; do not duplicate the full skill library.
4. Give Codex the business goal and instruct it to use `seo-workflow-system`; routing selects the needed SEO/WB specialists.

See `docs/` for setup, usage, routing and update procedures.
