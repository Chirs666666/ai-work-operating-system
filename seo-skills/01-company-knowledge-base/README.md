# 01 Company Knowledge Base

A reusable B2B company/product truth-base skill. `SKILL.md` is the entrypoint; detailed rules live in `references/`; canonical output forms in `templates/`; machine validation contracts in `schemas/`; and a fictional worked example in `examples/`.

## Core rule
Facts, evidence, inference, conflicts, and missing information remain distinguishable. Downstream skills consume truth artifacts but do not silently rewrite verified facts.

## V1 scope
Markdown + YAML + JSON Schema. No automation scripts are included in v1.0.0.
