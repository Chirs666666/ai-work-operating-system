# Proof Slot Rules
Accepted proof types: SPECIFICATION, TEST_DATA, CASE_STUDY, CERTIFICATE, FACTORY_IMAGE, CUSTOMER_RESULT, VIDEO, PROCESS_IMAGE, TECHNICAL_DOCUMENT, OTHER_VERIFIED_EVIDENCE. Proof status: AVAILABLE, MISSING, CONFLICTING, UNKNOWN. MISSING proof triggers REQUEST_EVIDENCE and/or REMOVE_UNSUPPORTED_CLAIM. Never fabricate proof.
