# 1. Purpose
Improve the probability that generative systems can correctly understand, extract, attribute and cite useful information while measuring visibility cautiously.

# 2. Trigger
Use for GEO audits, entity/claim/evidence audits, citation readiness, AI-query observation sets, brand-topic association and GEO optimization briefs.

# 3. Do Not Trigger
Do not promise AI citations/recommendations. Do not infer success from one mention. Do not infer SEO failure from no AI mention. Never invent facts/evidence. Do not overwrite proven SEO assets for speculative GEO gains.

# 4. Inputs
Target page/topic/brand, company/product facts, source evidence, current content, entity relationships, structured-data observations, AI query set/observations and SEO preservation constraints.

# 5. Preconditions
Separate sourced facts from unknowns. Unsupported high-impact claims must be blocked/revised. Preserve existing ranking/equity evidence before recommending structural rewrites.

# 6. Workflow
TARGET → ENTITY → INTENT → ANSWERABILITY → EXTRACTABILITY → CLAIM/EVIDENCE → ATTRIBUTION → RELATIONSHIPS → CITATION READINESS → BRAND ASSOCIATION → STRUCTURED DATA → AI OBSERVATIONS → GAPS → PRIORITY → SEO SAFETY → VERIFY.

# 7. Tool Routing
Use page/source evidence first. AI visibility is observational and platform/query/date dependent. Structured data is supporting evidence, not a citation guarantee.

# 8. Decision Rules
Prefer entity + attribute + value + application + boundary + evidence. Keep claims precise and evidence proximate. Repeated query-set observations are stronger than one prompt.

# 9. Quality Gates
G24: PASS, WARN, FAIL, BLOCK, REUSE, WAITING_APPROVAL.

Use the 24 canonical outputs in references/canonical-outputs.md.
