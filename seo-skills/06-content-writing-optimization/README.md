# 06 Content Writing & Optimization

Informational Content Lifecycle Skill.

**Modes:** CREATE / UPDATE / REFRESH / REWRITE  
**Architecture:** Shared Content Core + Mode-Specific Workflow  
**Layers:** Research → Strategy → Writing → QA → G06

The Skill is research-first, evidence-aware, Information-Gain driven, and diagnosis-first for existing content. It deliberately separates content readiness from metadata, internal-link execution, technical SEO, indexing/ranking validation, and GEO validation.
