# 1. Purpose
Improve existing commercial pages without needless rewrites or responsibility overlap.

# 2. Trigger
Use for existing PRODUCT, CATEGORY, SERVICE, APPLICATION, INDUSTRY, CAPABILITY, LANDING_PAGE, or HOME commercial-module audits and optimization.

# 3. Do Not Trigger
Do not use for informational articles (06), new-page planning (04), SEO metadata ownership (09), URL ownership/cannibalization (25), internal-link architecture (08), technical SEO repair (12), page speed (21), or WordPress writes (07).

# 4. Inputs
Use current page content, 25 ownership, 01 truth, 02 business model, 03 keyword research, optional 15 inventory, optional 13/GSC/GA4 performance, and relevant existing outputs from 04/05/08/09. Data may come from USER_DATA, API_DATA, or PUBLIC_RESEARCH. Missing data is UNKNOWN, never zero.

# 5. Preconditions
Identify page type, current URL, intended ownership, current live/draft state, and available performance/trust evidence before selecting change depth.

# 6. Workflow
INPUT NORMALIZATION → OWNERSHIP CHECK → CURRENT PAGE SNAPSHOT → PERFORMANCE BASELINE → DIAGNOSIS → PRESERVE REGISTER → ISSUE OWNERSHIP → CHANGE DEPTH → OPTIMIZATION STRATEGY → SECTION CHANGE PLAN → REVISED COPY WHEN JUSTIFIED → EVIDENCE CHECK → CONVERSION REVIEW → CROSS-SKILL HANDOFFS → CHANGE CONTROL → G10 → 07 EXECUTION → VERIFY.
Modes: AUDIT_PAGE, OPTIMIZE_PAGE, REFRESH_PAGE, REWRITE_PAGE, BATCH_AUDIT, VERIFY.

# 7. Tool Routing
Route by capability and source type. Read `references/tool-routing.md`.

# 8. Decision Rules
Actions: KEEP, MINOR_OPTIMIZE, SECTION_OPTIMIZE, STRUCTURAL_REFRESH, REWRITE, HOLD, BLOCK_FOR_OWNERSHIP. Preserve useful rankings, evidence, buyer detail, conversion paths, and proven page elements. Unsupported claims cannot enter revised copy.

# 9. Quality Gates
G10: PASS, WARN, FAIL, BLOCK, REUSE, WAITING_APPROVAL. Any live-page execution remains approval-controlled.

# 10. Outputs
Use the 18 canonical outputs in `references/canonical-outputs.md`.

# 11. Handoff
Ownership conflicts → 25. Metadata → 09. Internal links → 08. Technical SEO → 12. Page speed → 21. Major UI blueprint → 04. WordPress execution → 07. Product rewrite specialization may hand off to 05 when project workflow requires it.

# 12. Safety / Change Control
Never fabricate claims, turn missing metrics into zero, promise ranking/conversion gains, hide cannibalization with copy changes, or directly modify live WordPress. High-impact live rewrites require approval.
