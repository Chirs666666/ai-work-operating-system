# Change Depth Model
Actions: KEEP, MINOR_OPTIMIZE, SECTION_OPTIMIZE, STRUCTURAL_REFRESH, REWRITE, HOLD, BLOCK_FOR_OWNERSHIP.
KEEP preserves the page. MINOR_OPTIMIZE changes local clarity/proof/CTA. SECTION_OPTIMIZE materially revises one or more weak sections. STRUCTURAL_REFRESH changes hierarchy/section flow or adds missing commercial modules. REWRITE is for pages that cannot efficiently be repaired while preserving intent. HOLD means insufficient evidence or excessive risk. BLOCK_FOR_OWNERSHIP returns to 25.
