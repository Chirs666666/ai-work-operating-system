# Permission and Change Control

Auto-allowed:
- create Draft;
- update unpublished Draft;
- read/read-back;
- structure/visual/responsive/content-integrity QA;
- low-risk Draft repair that preserves upstream decisions.

Explicit approval required:
- publish;
- update live page;
- delete page;
- bulk page changes;
- plugin install/activation/deactivation;
- theme/global design/global template/sitewide settings changes;
- builder migration;
- similarly irreversible, broad, or high-impact mutation.

Before approved live mutation, capture target page ID, current status, prior revision/snapshot reference where available, previous slug/title when relevant, and intended material changes. If reliable recovery information is unavailable for a high-impact operation, do not auto-proceed.
