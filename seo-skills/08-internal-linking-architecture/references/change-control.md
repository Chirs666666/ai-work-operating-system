# Change Control
Existing-site change classes: `KEEP`, `IMPROVE`, `REPLACE`, `REMOVE_RECOMMENDATION`, `TECHNICAL_ISSUE`. Preserve first. Change scopes: `SINGLE_PAGE`, `SMALL_BATCH`, `BULK`, `SITEWIDE`. `REPLACE`, `REMOVE_RECOMMENDATION`, bulk/sitewide live changes and sitewide navigation/footer changes require `WAITING_APPROVAL`. Record before, after, reason, evidence, risk and scope.
