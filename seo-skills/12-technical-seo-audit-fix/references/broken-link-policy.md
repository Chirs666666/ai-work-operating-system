# Broken Link Policy
For each broken link record source URL, target URL, internal/external, observed status, anchor/context if available, probable cause, and resolution.
Actions: UPDATE_TARGET, REMOVE_LINK, RESTORE_TARGET, REDIRECT_TARGET, LEAVE_AS_IS, INVESTIGATE, BLOCK_FOR_OWNERSHIP.
A 404 does not automatically justify a redirect. Redirect only when there is a clear relevant replacement and ownership is valid.
