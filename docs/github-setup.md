# GitHub Setup
1. Create a private repository, e.g. `ai-work-operating-system`.
2. Upload/push the contents of this distribution as the repository root.
3. Treat GitHub as Source of Truth: edit, review, tag and release skills here.
4. Never commit runtime secrets, API keys, passwords or client credentials.
5. For a skill update, change the source, validate it, bump its version, then update the Codex runtime copy.
