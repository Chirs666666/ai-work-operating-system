# How to Use
## Complex project
`Use seo-workflow-system. Build a new English B2B site with SEO and WordPress. Discover existing artifacts first. Do not deploy production without my approval.`

## Specialist task
`Use 03-product-keyword-research for collaborative welding robot, then hand the artifact to 25-keyword-page-mapping.`

## Build-only task
`Use website-build-layer. Discover existing SEO/build artifacts first and route only required WB skills. Keep WB08 waiting for approval.`

Default operating pattern:
GOAL → DISCOVER → ROUTE → RUN/REUSE/VERIFY/SKIP/DRAFT_ONLY → GATE → APPROVAL → HANDOFF → CLOSEOUT.
