# WB01 Site Architecture Builder

Builds the website information architecture for a new site, rebuild, expansion, or migration plan before WordPress implementation.

## Position
Typical upstream inputs: 01 Company Knowledge Base, 02 Business Model Analysis, 03 Product Keyword Research, 25 Keyword Page Mapping.

Typical downstream consumers: 04 Page Planning/UI, 08 Internal Linking Architecture, 09 SEO Metadata, WB02 WordPress Foundation Setup, WB03 Global Components Builder, WB04 Website Page Assembly.

## Key boundary
WB01 plans architecture. It does not authorize or execute live URL, redirect, canonical, noindex, production navigation, or WordPress changes.
