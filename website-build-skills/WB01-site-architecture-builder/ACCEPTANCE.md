# Acceptance

WB01 is acceptable when:
- required package files are present;
- every canonical output has a Draft 2020-12 schema and template;
- schemas validate and templates conform;
- example projects validate;
- duplicate URLs are rejected;
- duplicate intent/ownership without differentiation is rejected;
- Skill 25 ownership cannot be silently overridden;
- live URL changes cannot be treated as pre-approved;
- missing evidence is preserved as UNKNOWN/null;
- ZIP inventory matches the source package and archive integrity passes.
