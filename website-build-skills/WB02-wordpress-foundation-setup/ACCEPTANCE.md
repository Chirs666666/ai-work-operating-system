# Acceptance

WB02 is acceptable when:
- required package files exist;
- every canonical output has a Draft 2020-12 schema and YAML template;
- schemas, templates and examples validate;
- permalink/WB01 conflicts are blocked;
- unapproved production changes are not treated as approved;
- risky production changes without backup/rollback readiness are blocked;
- duplicate SEO plugin ownership is rejected;
- incompatible duplicate cache/security ownership is rejected;
- UNKNOWN evidence is not promoted to verified state;
- ZIP inventory and integrity pass.
